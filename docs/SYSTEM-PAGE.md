# Author's System Page

The public explanation must distinguish three layers:

- **Established** — supported directly by the project's evidence.
- **Project policy** — an explicit design choice for practical Ukrainian output.
- **Analysis dependent / evidence limited** — cases requiring stronger evidence or contextual analysis.
