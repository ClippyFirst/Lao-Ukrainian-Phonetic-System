# Lao → Cyrillic comparison

## Russian baseline

The Russian practical tradition is a genuine Lao practical-transcription tradition associated with Morev, Moskalev and Plam, Lao-Russian dictionary practice and Boiko's geographical-name work. It is position-sensitive: consonants have separate initial/final behavior and vowels have separate short/long renderings.

| Lao IPA | Russian | Ukrainian project |
|---|---|---|
| /kʰ/ | кх | к |
| /pʰ/ | пх | п |
| /tʰ/ | тх | т |
| /ŋ/ | нг | нг |
| /tɕ/ | ть | ч |
| /h/ | х | г |
| /ɯ/ | ы | и |
| /ɤ/ | е | е, explicit approximation |
| /ɛ/ | э | е |
| /aː/ | аа | а |

The Ukrainian column is not an official national standard. It is generated after IPA analysis.

## Why not copy Russian

The target-language question is: which Ukrainian phoneme/grapheme best approximates the same Lao IPA under Ukrainian phonological and orthographic constraints? Russian Cyrillic is therefore evidence and a comparator, never an intermediate representation.

Russian кх/пх/тх is not mechanically inherited; aspiration remains visible in IPA while practical Ukrainian uses к/п/т. Russian х for Lao /h/ is not automatically optimal because Ukrainian has /ɦ/, so the project uses г with explicit non-identity status. Lao /ɯ/ is represented by Ukrainian и, not Russian ы. Lao /tɕ/ is represented by Ukrainian ч.

## Serbian control

Serbian is not treated as a Lao-specific transcription system. It is a target-script control. Official Serbian geographical-name material gives the capital as **Вијентијан**, demonstrating target-language-specific adaptation.

## Bulgarian control

Bulgarian official material gives **Виентян**. Bulgarian UNGEGN material explicitly describes transcription as using the means of Bulgarian language and its orthography/literary pronunciation. This is methodological evidence that target-language phonology matters.

## Traditional names

Conventional/exonymic forms must remain separate from regular algorithmic outputs. A historical spelling must not be fed back as a universal phonological rule without evidence.
