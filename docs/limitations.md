# Limitations and unresolved questions

1. **Unspaced multi-syllable text.** The current public parser accepts explicit syllable/phrase chunks and ZWSP boundaries. Full automatic syllable segmentation is not yet a validated lexical parser.
2. **Initial clusters.** The restricted modern labialized onset inventory and silent high-class `ຫ` sequences are now modeled in the canonical parser and browser engine. The eleven grapheme forms cover eight source-listed `ʷ` onsets; rounded-vowel clusters are rejected, and `Cວາ` overlap between a labialized onset + AA and the UO-long-open rhyme is withheld as ambiguous. No Ukrainian target correspondence is yet registered for `ʷ` IPA sequences, so these remain IPA-only (`EVIDENCE LIMITED`). The parser does not claim automatic lexical disambiguation of every unmarked `Cວ` sequence.
3. **ໜ/ໝ.** Unicode defines these as sequences corresponding to [h]+[n]/[m] with special tonal implications. The repository currently preserves them structurally but does not claim a complete independent tonal grammar for every such form.
4. **Pali/Sanskrit.** Extended letters and virama are registered separately but are not part of the modern-Lao core output model.
5. **Tone contours.** The five-tone Vientiane system is well supported, but exact contour notation varies among descriptions.
6. **Ukrainian target.** The target correspondences are project decisions. They are not presented as an adopted Ukrainian national standard.
7. **Lexical exceptions and conventional names.** A regular phonological algorithm cannot by itself establish every conventional geographical or personal-name spelling.
8. **Empirical accuracy.** No gold-standard adjudicated corpus is currently available, so no accuracy percentage is claimed.


9. **Romanization syllable adapter.** The optional Ukrainian-by-romanization mode depends on the constrained provisional CLDR Lao-Latin/BGN transform. The CLDR file itself marks the profile provisional and leaves special final-consonant handling as TODO. The adapter now cross-checks romanized onsets, supported vowel nuclei and codas against the original Lao syllable analysis: `kh/th/ph` are aspirated-stop spellings and map to `к'/т'/п'`, while standalone `h` from ຫ/ຮ maps to `г`. The `x` alias for ຊ maps to `с`, not literal `кс`. It cannot restore tone or other distinctions absent from romanization. Lao spaces are phrase-level, not syllable boundaries; concatenated romanized strings can have multiple valid segmentations. Ambiguous, mismatched or unsupported segments are therefore withheld and marked partial rather than guessed. Final `h` is rejected because it is not a supported Lao coda. BGN/PCGN note 5 identifies ໜ/ໝ as abbreviated forms of silent ຫ + ນ/ມ and says silent ຫ is generally omitted before sonorants. The adapter now applies this to the supported forms ຫງ, ຫຍ, ຫນ, ຫມ, ຫລ, ຫຼ, ຫວ and atomic ໜ/ໝ, preserving the underlying sonorant rather than inventing an /h/. The BGN /r/ environment ຫຣ is not yet represented by the structural parser and remains unsupported. Source vowel IDs can disambiguate homographic CLDR forms such as `kam` (A + coda m versus AM nucleus); without the original Lao structure, ambiguous forms remain partial. The crosswalk currently covers a documented subset of vowel IDs, not every orthographic pattern. This is not a pronunciation guarantee. The source romanization is not an UN-approved Lao national standard.
